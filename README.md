# 料理メモ 🍳

個人用レシピ記録アプリ。GitHub Pages でホスティングされ、データはブラウザの localStorage に保存されます。

## URL

https://sayakaorukasumi.github.io/cokkingmemo/

## 機能

- レシピ登録・編集・削除
- 写真付きレシピ（端末内で圧縮保存）
- 気力レベル・調理時間・野菜の存在感などのフィルター
- お気に入り登録
- 作った記録（料理ログ）
- 栄養メモ（カロリー・たんぱく質・脂質・炭水化物・食物繊維）
- タグ・コメント機能

## 技術スタック

- Next.js 16 (Static Export)
- Tailwind CSS v4
- localStorage（外部DBなし）
- GitHub Pages + GitHub Actions
